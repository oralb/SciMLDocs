Attempts at a single documentation for the full SciML interface.

## Personal SciML self-study notebook

[Learn SciML by growing a virtual plant](notebooks/sciml_self_study.jl) is an interactive
Pluto notebook for learning Julia and SciML at your own pace. It connects ODE simulation,
accuracy checks, events, equilibria, optimization, fitting synthetic observations,
automatic differentiation, and a learned growth correction, with ten exercises and
revealable answers.

See the [notebook quick start](notebooks/README.md) for installation, a suggested study
sequence, and numerical verification. The notebook has its own embedded environment;
you do not need to build the documentation site.
